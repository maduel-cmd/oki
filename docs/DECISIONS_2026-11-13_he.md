## פריסה (לא בוצעה)

1. להריץ את `20261113000011_security_hardening.sql` בפרויקט Supabase (משותף עם TrailLink — לבדוק קודם ב-branch).
2. לפרוס מחדש את Edge Function `family-livekit-token`.
3. `npm run deploy:netlify`.

הלקוח החדש סובל היעדר טבלת המיקומים (לפני המיגרציה), אך שיתוף מיקום ייכשל עד שהמיגרציה תרוץ — לכן סדר הפריסה: DB ← Edge ← Netlify.
