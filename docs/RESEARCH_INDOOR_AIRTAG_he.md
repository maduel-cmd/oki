# מחקר: טלפון כ־AirTag ומיקום בתוך מבנים (שדה תעופה)

עודכן: 2026-08-29 · למוצר «אוקי משפחה» (PWA)

## השאלה

1. האם אפשר להפוך כל טלפון ל־«AirTag» כך שבני משפחה יראו זה את זה **בלי GPS**?
2. האם אפשר לדעת מיקום **בתוך מבנה** (טרמינל / שדה תעופה) ברמת דיוק שמאפשרת להגיע אחד לשני?

## מסקנה קצרה

| רעיון | אפשרי ב־PWA של אוקי? | הערה |
| --- | --- | --- |
| רשת Find My של Apple (כמו AirTag) | **לא** | סגורה ליצרני אביזרים בתוכנית MFi; אין API לאפליקציות צד־ג׳ להפוך iPhone ל־tag ברשת של כולם |
| רשת Find Hub / Find My Device של Google | **לא ל־PWA** | לשותפי חומרה מאושרים (Fast Pair / Locator Tag); אין SDK ציבורי לאפליקציית ווב |
| GPS + שיתוף בענן (מה שיש היום) | **כן** | עובד בחוץ; חלש/נעלם במבנים |
| BLE בין טלפונים קרובים | **חלקי מאוד** | Web Bluetooth מוגבל; לא רשת עולמית כמו AirTag; דורש קרבה + תמיכת דפדפן |
| Beacons / Wi‑Fi במבנה | **כן, אבל תלוי מקום** | דורש תשתית בשדה התעופה (או ספק מפות פנים) — לא «כל טלפון = tag» לבד |
| מיקום ויזואלי (VPS/מצלמה) | **מוגבל ב־PWA** | בעיקר ב־SDK נייטיב / ספקים; לא פתרון אוניברסלי לכל שדה תעופה |

**שורה תחתונה:** אי אפשר לשכפל את מודל AirTag ב־PWA בלי גישה לרשתות הסגורות של אפל/גוגל. מיקום במבנים אפשרי רק עם GPS חלש + בקשת מיקום (כמו היום), או עם שותף מפות־פנים / Beacons במבנה ספציפי, או אפליקציה נייטיבית בעתיד.

## מה כן עובד היום באוקי (ומה נוסף עכשיו)

- על המפה: **תווית שם קטנה** לכל בן משפחה שיש לו מיקום ידוע (אני + מי ששיתף להורים — לפי נעילת פרטיות).
- מחוברים בלי מיקום משותף מופיעים בכיתוב מתחת למפה (לא נקודה על המפה — אין קואורדינטה).

## חלופות טכנולוגיות למיקום במבנה

1. **GPS + שיתוף חד־פעמי / לפי בקשה** (נוכחי) — פשוט, שומר פרטיות; בשדה תעופה לעיתים רק «אזור כללי».
2. **ספק Indoor (Situm / Mapxus / Proximi.io / Digimap וכו׳)** — מפות קומות + BLE/Wi‑Fi/QR; דורש חוזה + כיסוי למבנה.
3. **אפליקציה נייטיבית (Expo) + UWB/BLE** — דיוק טוב יותר בין מכשירים קרובים (לא כמו AirTag עולמי).
4. **נקודות מפגש ידניות** באפליקציה (סיכה על מפת הטרמינל / «אני ליד שער 12») — בלי תשתית חומרה.

## המלצה למוצר

להמשיך עם מפת שמות + שיתוף לפי בקשה; לא להבטיח «AirTag בלי GPS».  
אם רוצים שדה־תעופה ברצינות — לבחור פיילוט עם ספק Indoor או מצב «נקודת מפגש» ידנית לפני השקעה ברשת תגיות.
